# Web Security Analyzer

This is a beginner-level cybersecurity project built using Python.

## Features
- Checks whether a website uses HTTPS
- Analyzes presence of basic security-related HTTP headers
- Helps understand web application security fundamentals

## Tech Stack
- Python
- Requests library

## Purpose
This project was built to strengthen my understanding of web security,
HTTP headers, and how applications expose security-related information.
